# Speech Processing Assignment - HMM-DNN Based Automatic Speech Recognition

## Course
BITS Pilani  
AIMLCZG520 - Speech Processing

## Assignment Topic

Hybrid Automatic Speech Recognition (ASR) System using Deep Neural Network (DNN) integrated with Hidden Markov Model (HMM).

---

## Problem Statement

Develop a speech recognition system using a hybrid HMM-DNN approach.

The system performs:
- Speech preprocessing
- Acoustic feature extraction
- Deep Neural Network based acoustic modelling
- HMM based temporal modelling
- Viterbi decoding
- Word Error Rate (WER) evaluation
